## 개념

**Kyber**(정식 이름 ML-KEM)는 LWE를 실제로 쓸 수 있게 만든 양자내성 암호다. 숫자 하나 대신 **다항식**(계수가 256개인 식)을 쓰고, 그걸 여러 개 묶은 **벡터**를 쓴다.

### 공개키 만들기

$$
\text{공개키} = A \times \text{비밀} + \text{작은 오차}
$$

LWE 방정식 그 자체다. $A$는 랜덤 행렬인데, 그대로 보내면 너무 크다. 그래서 **32바이트 씨앗(seed)**만 보내고 받는 쪽이 씨앗으로 $A$를 다시 만든다.

### 직접 계산해보기 (Kyber1024의 공개키 크기)

| 부분 | 계산 | 크기 |
|---|---|---|
| 다항식 하나 | 계수 256개 × 12비트 ÷ 8 | 384바이트 |
| 다항식 4개 (k = 4) | 384 × 4 | 1536바이트 |
| 씨앗 | | 32바이트 |
| **합계** | 1536 + 32 | **1568바이트** |

계수 하나가 12비트인 이유는 Kyber의 $q = 3329$가 $2^{12} = 4096$보다 작기 때문이다.

### 정리

**Kyber**(표준명 ML-KEM)는 NIST가 표준화한 양자내성 키 캡슐화 방식이다. 숫자 하나 대신 **다항식 벡터**를 쓰는 Module-LWE를 기반으로 한다.

- 다항식 환 $R_q = \mathbb{Z}_q[x]/(x^{256} + 1)$, $q = 3329$
- 공개키는 $t = A s + e$와 행렬 $A$를 만드는 32바이트 시드 $\rho$
- Kyber1024는 모듈 차원 $k = 4$

다항식 하나는 계수 256개이고, 각 계수는 12비트($q < 2^{12}$)다. 그래서 크기는 $256 \times 12 / 8 = 384$바이트다.

## 문제

Kyber1024 공개키가 몇 바이트인지 묻는다.

## 풀이

다항식 4개와 시드를 더하면 $4 \times 384 + 32 =$ **1568**바이트다.

## 풀이 코드
```python
k = 4
poly_bytes = 384
seed_bytes = 32
print(k * poly_bytes + seed_bytes)
```
