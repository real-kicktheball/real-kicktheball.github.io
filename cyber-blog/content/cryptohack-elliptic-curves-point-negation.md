## 개념

곡선은 x축 기준으로 위아래가 대칭이다. 그래서 점 $P = (x, y)$의 "반대편 점"은 $(x, -y)$다. 이걸 $-P$라고 쓴다.

$$
P + (-P) = O
$$

$O$는 **무한원점**이라는 특별한 점이다. 덧셈에서 0 같은 역할을 한다. 어떤 점에 $O$를 더해도 그대로다.

### 나머지 세계에서 $-y$는?

암호에서는 좌표도 "$p$로 나눈 나머지"를 쓴다. 그래서 음수 대신 $p - y$를 쓴다.

### 직접 해보기 ($p = 11$, $P = (3, 4)$)

$$
-P = (3,\ -4 \bmod 11) = (3,\ 7)
$$

확인해보자. $4 + 7 = 11 \equiv 0$이다. y좌표끼리 더하면 0이 되니까 정말 반대편 점이다.

### 정리

타원곡선은 x축 대칭이다. $(x, y)$가 곡선 위에 있으면 $(x, -y)$도 곡선 위에 있다. $P$와 $-P$를 잇는 직선은 수직선이라 세 번째 교점이 무한원점 $O$이다. 그래서 다음이 성립한다.

$$
P + (-P) = O, \qquad -P = (x, -y)
$$

유한체 $\mathbb{F}_p$에서는 $-y$를 $p - y$로 쓴다.

## 문제

곡선 $E: y^2 = x^3 + 497x + 1768 \pmod{9739}$와 $P = (8045, 6936)$이 주어진다. $P + Q = O$인 $Q$를 구한다.

## 풀이

$Q = -P = (8045,\ -6936 \bmod 9739) = (8045, 2803)$이다.

## 풀이 코드
```python
p = 9739
x, y = 8045, 6936
q = (x, -y % p)
assert (y+q[1]) % p == 0
print(f'crypto{{{q[0]},{q[1]}}}')
```

## 플래그
`crypto{8045,2803}`
