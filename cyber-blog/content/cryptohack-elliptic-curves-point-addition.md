## 개념

곡선 위의 두 점을 더하는 방법은 **그림으로** 이해하면 쉽다.

1. 두 점 $P$, $Q$를 지나는 **직선**을 긋는다.
2. 이 직선은 곡선과 **한 군데 더** 만난다(세 번째 점).
3. 그 세 번째 점을 x축 기준으로 **뒤집는다**.
4. 뒤집은 점이 $P + Q$다.

$P$와 자기 자신을 더할 때($P + P$)는 직선 대신 **접선**(곡선에 살짝 닿는 선)을 긋는다.

### 계산 방법

먼저 직선의 **기울기** $\lambda$를 구한다.

$$
\lambda = \frac{y_2 - y_1}{x_2 - x_1}
$$

그다음 새 점의 좌표를 구한다.

$$
x_3 = \lambda^2 - x_1 - x_2, \qquad y_3 = \lambda(x_1 - x_3) - y_1
$$

나머지 세계에는 분수가 없다. 그래서 "나누기"는 **역원을 곱하는 것**으로 바꾼다.

### 직접 해보기 ($y^2 = x^3 + 2x + 3$, $p = 97$, $P = (3, 6)$, $Q = (80, 10)$)

1. 기울기: $\lambda = \frac{10 - 6}{80 - 3} = \frac{4}{77}$
2. 77의 역원을 구하면 $77 \times 63 = 4851 = 50 \times 97 + 1$이라서 63이다.
3. $\lambda = 4 \times 63 \bmod 97 = 252 \bmod 97 = 58$
4. $x_3 = 58^2 - 3 - 80 = 3364 - 83 = 3281 \bmod 97 = 80$
5. $y_3 = 58 \times (3 - 80) - 6 = -4472 \bmod 97 = 87$

$P + Q = (80, 87)$이다. 이 점은 $Q = (80, 10)$의 반대편 점($10 + 87 = 97$)이다.

### 정리

**점 덧셈**의 기하학적 의미는 다음과 같다.

1. $P$와 $Q$를 지나는 직선을 긋는다.
2. 곡선과 만나는 세 번째 점을 찾는다.
3. 그 점을 x축 대칭시킨 것이 $P + Q$다.

$P = Q$이면 접선을 쓴다. 이걸 식으로 쓰면 다음과 같다.

$$
\lambda =
\begin{cases}
\dfrac{y_2 - y_1}{x_2 - x_1} & P \ne Q \\[2mm]
\dfrac{3x_1^2 + a}{2y_1} & P = Q
\end{cases}
$$

$$
x_3 = \lambda^2 - x_1 - x_2, \qquad y_3 = \lambda(x_1 - x_3) - y_1
$$

유한체에서는 나눗셈을 **모듈러 역원 곱셈**으로 바꾼다. 특수한 경우도 처리해야 한다.

- $P = O$이면 결과는 $Q$다.
- $x_1 = x_2$, $y_1 = -y_2$이면 결과는 $O$다.

## 문제

같은 곡선에서 $P = (493, 5564)$, $Q = (1539, 4742)$, $R = (4403, 5202)$일 때 $S = P + P + Q + R$을 구한다.

## 풀이

1. 위 공식으로 `add` 함수를 만든다.
2. 문제의 예시 $X + Y = (1024, 4440)$, $X + X = (7284, 2107)$로 함수를 먼저 검증한다.
3. 결과가 곡선 위에 있는지도 확인했다.
4. $S = (4215, 2162)$이다.

## 풀이 코드
```python
p, a, b = 9739, 497, 1768
O = None

def on_curve(P):
    return P is None or (P[1]**2 - P[0]**3 - a*P[0] - b) % p == 0

def add(P, Q):
    if P is None: return Q
    if Q is None: return P
    x1, y1 = P
    x2, y2 = Q
    if x1 == x2 and (y1 + y2) % p == 0: return O
    if P == Q:
        slope = (3*x1*x1+a)*pow(2*y1, -1, p) % p
    else:
        slope = (y2-y1)*pow(x2-x1, -1, p) % p
    x3 = (slope*slope-x1-x2) % p
    return (x3, (slope*(x1-x3)-y1) % p)

def mul(n, P):
    R = O
    while n:
        if n & 1: R = add(R, P)
        P = add(P, P)
        n >>= 1
    return R
assert add((5274,2841), (8669,740)) == (1024,4440)
assert add((5274,2841), (5274,2841)) == (7284,2107)
S = add(add(add((493,5564), (493,5564)), (1539,4742)), (4403,5202))
assert on_curve(S)
print(f'crypto{{{S[0]},{S[1]}}}')
```
