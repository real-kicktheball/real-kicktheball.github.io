## 개념

해시 함수의 안전성은 세 가지로 나눈다.

| 성질 | 어려워야 하는 것 | 일반 공격 비용 |
|---|---|---|
| 원상 저항성 | $H(x) = h$인 $x$ 찾기 | $2^n$ |
| 2차 원상 저항성 | 주어진 $x$에 대해 $H(x') = H(x)$인 $x'$ 찾기 | $2^n$ |
| 충돌 저항성 | $H(x) = H(x')$인 아무 쌍 찾기 | $2^{n/2}$ |

**특정 값 하나**를 맞히는 건 매 시도가 독립이다. 한 번에 맞을 확률이 $1/N$이면 $k$번 안에 한 번이라도 맞을 확률은 다음과 같다.

$$
1 - \left(1 - \frac{1}{N}\right)^k
$$

## 문제

JACK11은 11비트 해시다($N = 2^{11} = 2048$). 내 비밀 해시와 같은 해시를 50% 확률로 찾으려면 몇 개의 서로 다른 입력을 해시해야 하는가?

## 풀이

다음 식을 $k$에 대해 풀면 된다.

$$
1 - \left(1 - \tfrac{1}{2048}\right)^k \ge 0.5 \ \Rightarrow\ k \ge \frac{\ln 0.5}{\ln(1 - 1/2048)} \approx 1419.2
$$

올림해서 **1420**이다. 대략 $N \ln 2$로 근사되는 값이다.

## 풀이 코드
```python
import math
N = 2**11
n = math.ceil(math.log(0.5)/math.log(1-1/N))
assert 1-(1-1/N)**(n-1) < 0.5 <= 1-(1-1/N)**n
print(n)
```

## 플래그
`1420`
