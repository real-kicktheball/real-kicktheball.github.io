## 개념

**해시 함수**는 아무 데이터를 넣어도 **정해진 길이의 지문**을 만들어주는 함수다.

| 성질 | 설명 |
|---|---|
| 같은 입력 → 같은 지문 | 항상 똑같이 나온다 |
| 조금만 달라도 완전히 다른 지문 | `cat`과 `cab`의 지문은 전혀 닮지 않았다 |
| 거꾸로 못 간다 | 지문만 보고 원래 데이터를 알 수 없다 |

비밀번호 저장, 파일이 바뀌었는지 확인하기 등에 쓴다.

### 특정 지문을 맞히려면?

이 문제의 해시(JACK11)는 지문이 11비트다. 가능한 지문은 $2^{11} = 2048$가지다. 내 지문과 **똑같은 지문**이 나오는 다른 입력을 찾으려면 몇 번 시도해야 할까?

한 번 시도할 때 맞을 확률은 $\frac{1}{2048}$이다. 2048번 하면 꼭 맞을 것 같지만, 운이 나쁘면 계속 빗나간다.

### 직접 해보기 (주사위로 생각하기)

주사위를 던져서 "6"이 한 번이라도 나올 확률은 다음과 같다.

- 1번 던지면: $\frac{1}{6} \approx 17\%$
- 4번 던지면: $1 - \left(\frac{5}{6}\right)^4 \approx 52\%$

4번이면 50%를 넘는다. 같은 방법으로 2048가지 지문에서 계산하면 **1420번** 시도해야 50%를 넘는다.

### 정리

해시 함수의 안전성은 세 가지로 나눈다.

| 성질 | 어려워야 하는 것 | 일반 공격 비용 |
|---|---|---|
| 원상 저항성 | $H(x) = h$인 $x$ 찾기 | $2^n$ |
| 2차 원상 저항성 | 주어진 $x$에 대해 $H(x') = H(x)$인 $x'$ 찾기 | $2^n$ |
| 충돌 저항성 | $H(x) = H(x')$인 아무 쌍 찾기 | $2^{n/2}$ |

**특정 값 하나**를 맞히는 건 매 시도가 독립이다. 한 번에 맞을 확률이 $1/N$이면 $k$번 안에 한 번이라도 맞을 확률은 다음과 같다.

$$
1 - \left(1 - \frac{1}{N}\right)^k
$$

## 문제

JACK11은 11비트 해시다($N = 2^{11} = 2048$). 내 비밀 해시와 같은 해시를 50% 확률로 찾으려면 몇 개의 서로 다른 입력을 해시해야 하는가?

## 풀이

다음 식을 $k$에 대해 풀면 된다.

$$
1 - \left(1 - \tfrac{1}{2048}\right)^k \ge 0.5 \ \Rightarrow\ k \ge \frac{\ln 0.5}{\ln(1 - 1/2048)} \approx 1419.2
$$

올림해서 **1420**이다. 대략 $N \ln 2$로 근사되는 값이다.

## 풀이 코드
```python
import math
N = 2**11
n = math.ceil(math.log(0.5)/math.log(1-1/N))
assert 1-(1-1/N)**(n-1) < 0.5 <= 1-(1-1/N)**n
print(n)
```
