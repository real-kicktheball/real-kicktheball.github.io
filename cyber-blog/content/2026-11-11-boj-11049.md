# 행렬 곱셈 순서

## 문제

크기가 N×M인 행렬 A와 M×K인 B를 곱할 때 필요한 곱셈 연산의 수는 총 N×M×K번이다. 행렬 N개를 곱하는데 필요한 곱셈 연산의 수는 행렬을 곱하는 순서에 따라 달라지게 된다.

예를 들어, A의 크기가 5×3이고, B의 크기가 3×2, C의 크기가 2×6인 경우에 행렬의 곱 ABC를 구하는 경우를 생각해보자.

-   AB를 먼저 곱하고 C를 곱하는 경우 (AB)C에 필요한 곱셈 연산의 수는 5×3×2 + 5×2×6 = 30 + 60 = 90번이다.
-   BC를 먼저 곱하고 A를 곱하는 경우 A(BC)에 필요한 곱셈 연산의 수는 3×2×6 + 5×3×6 = 36 + 90 = 126번이다.

같은 곱셈이지만, 곱셈을 하는 순서에 따라서 곱셈 연산의 수가 달라진다.

행렬 N개의 크기가 주어졌을 때, 모든 행렬을 곱하는데 필요한 곱셈 연산 횟수의 최솟값을 구하는 프로그램을 작성하시오. 입력으로 주어진 행렬의 순서를 바꾸면 안 된다.

## 입력

첫째 줄에 행렬의 개수 N(1 ≤ N ≤ 500)이 주어진다.

둘째 줄부터 N개 줄에는 행렬의 크기 r과 c가 주어진다. (1 ≤ r, c ≤ 500)

항상 순서대로 곱셈을 할 수 있는 크기만 입력으로 주어진다.

## 출력

첫째 줄에 입력으로 주어진 행렬을 곱하는데 필요한 곱셈 연산의 최솟값을 출력한다. 정답은 231-1 보다 작거나 같은 자연수이다. 또한, 최악의 순서로 연산해도 연산 횟수가 231-1보다 작거나 같다.

## 예제 입력 1 

```
3
5 3
3 2
2 6
```

## 예제 출력 1 

```
90
```

## 기초 지식 및 문제 정리

선형대수학을 배웠으면 알 수 있겠지만 행렬의 곱은 순서에 따라 결과 값이 다릅니다 ( A \* B != B \* A )

첫 입력으로 행렬의 개수 (N)를 입력받고, 다음 줄부터 각 행렬의 크기를 N개 만큼 입력을 받습니다.

여기서 결과로 나와야 하는 값은 여러 행렬의 순서를 잘 조합해서 "곱셈 연산 자체"의 최솟값을 구하면 된다는 문제이네요.

하나의 조건이 더 있는데  "입력으로 주어진 행렬의 순서를 바꾸면 안된다"

예를 들어 설명하면 5개의 행렬을 입력한다고 했을 때 ABCDE 순서로 입력을 했는데 임의로 CABDE 등으로 바꾸면 안된다는 조건이 있네요. 결국 괄호 ()를 통해서 순서를 바꿀 수 있고 그 때의 최솟값이 출력이 되겠네요.

정리하면 

INPUT int N -> 행렬의 개수 입력

for i in range(N):

    INPUT int A, int B -> 각 행렬의 크기 입력

    APPPEND list L -> 각 행렬 크기 리스트에 추가

Algorithm(L)

이렇게 코드가 나오겠습니다.

그리고 리스트는 단일리스트로 구성하셔도 됩니다.

이유는 A = 3 \* 2 와 B = 2 \* 7 라는 행렬이 있다고 가정하면 결국 A의 열과 B의 행의 크기가 같아야 하기 때문에 단일리스트 \[3, 2, 7\] 으로 구현했습니다.

## 점화식 유도

그럼 이제 점화식을 유도해보겠습니다.

A, B라는 행렬이 있다는 가정 하에, A의 행 \* 공통 부분 \* B의 열이 A \* B의 과정에서 발생하는 "곱셈 연산"의 횟수입니다.

단일리스트 P = \[3, 2, 7\]을 예시로 설명해드리면, 

첫 번째 행렬의 행은 P\[0\], 열은 P\[1\]

두 번째 행렬의 행은 P\[1\], 열은 P\[2\]가 됩니다.

따라서 i번 째 행은 P\[i\], 열은 P\[i+1\]가 입니다.

행렬이 여러 개여도 똑같이 적용합니다.

이제 좀 더 예시를 자세히 들어드리겠습니다.

행렬 N(4)개, A = 5 \* 3, B = 3 \* 2, C = 2 \* 6, D = 6 \* 4 이면,

Matrix = \[5, 3, 2, 6, 4\]가 됩니다.

dp = \[\[0\] \* N for \_ in range(N)\] # DP 테이블 초기화

for d in range(1, N): # 시작점 위치

    for i in range(N - d): # 간격

        j = i + d  # 끝점 위치

        for k in range(i, j):

             \# \[점화식\] 왼쪽 비용 + 오른쪽 비용 + 합치는 비용

            cost = dp\[i\]\[k\] + dp\[k+1\]\[j\] + (matrix\[i\]\[0\] \* matrix\[k\]\[1\] \* matrix\[j\]\[1\])

             if cost < dp\[i\]\[j\]:

                 dp\[i\]\[j\] = cost

이렇게 정리됩니다.

## 최종 코드

이제 런타임과 각 변수의 크기를 고려하여 파이썬으로 작성해보겠습니다.

import sys

  

def solve():

    \# 입력을 빠르게 받기 위해 sys.stdin.readline 사용

    input \= sys.stdin.read().split()

    if not input:

        return

    N \= int(input\[0\])

    matrix \= \[\]

    idx \= 1

    for \_ in range(N):

        matrix.append((int(input\[idx\]), int(input\[idx+1\])))

        idx += 2

    dp \= \[\[0\] \* N for \_ in range(N)\]

    for d in range(1, N):

        for i in range(N \- d):

            j \= i + d

            dp\[i\]\[j\] \= 2147483647

            curr\_i\_row \= matrix\[i\]\[0\]

            curr\_j\_col \= matrix\[j\]\[1\]

            for k in range(i, j):

                cost \= dp\[i\]\[k\] + dp\[k+1\]\[j\] + (curr\_i\_row \* matrix\[k\]\[1\] \* curr\_j\_col)

                if cost < dp\[i\]\[j\]:

                    dp\[i\]\[j\] \= cost

  

    print(dp\[0\]\[N\-1\])

  

solve()
