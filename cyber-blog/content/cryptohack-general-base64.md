## 개념

옛날 이메일은 **글자만** 보낼 수 있었다. 그런데 사진 같은 파일은 글자가 아닌 이상한 값(바이트)으로 되어 있다. 그래서 파일을 "보낼 수 있는 글자"로 바꿔 포장하는 방법이 필요했다. 그게 **Base64**다.

Base64는 64개의 글자만 쓴다.

```
A~Z (26개) + a~z (26개) + 0~9 (10개) + + / (2개) = 64개
```

포장하는 방법은 다음과 같다.

1. 원래 데이터 3바이트(24칸짜리 0/1 줄)를 준비한다.
2. 6칸씩 4조각으로 자른다.
3. 6칸으로는 0~63을 나타낼 수 있으니, 각 조각을 64개 글자 중 하나로 바꾼다.

그래서 3바이트가 4글자가 된다. 포장하면 조금 길어진다.

### 직접 해보기

`Man`이라는 3글자를 Base64로 바꾸면 `TWFu`가 된다. 3글자가 4글자로 늘어났다.

### 이 문제에서 조심할 점

문제에서 준 건 **16진수 글자**다. 먼저 16진수를 원래 바이트로 되돌린 다음 Base64로 포장해야 한다. 16진수 글자를 그대로 포장하면 틀린다.

### 정리

**Base64**는 바이너리 데이터를 출력 가능한 64개 문자(`A-Z a-z 0-9 + /`)로 표현하는 인코딩이다.

- 3바이트(24비트)를 6비트씩 4조각으로 나눈다.
- 각 6비트 값(0~63)을 문자 하나에 대응시킨다.
- 그래서 결과 길이는 원본의 약 4/3배가 된다.

이메일 첨부파일이나 PEM 키처럼 텍스트만 다룰 수 있는 곳에서 바이너리를 옮길 때 쓴다.

## 문제

hex 문자열 `72bca9b68fc16ac7...`을 **바이트로 디코딩한 뒤** Base64로 인코딩하라는 문제다.

## 풀이

hex 문자열 자체를 Base64로 인코딩하면 안 된다. `bytes.fromhex()`로 원래 바이트를 먼저 복원하고 `base64.b64encode()`를 적용해야 한다. 이 문제의 답은 `crypto{}`로 감싸지 않은 Base64 문자열이다.

## 풀이 코드
```python
import base64
h = "72bca9b68fc16ac7beeb8f849dca1d8a783e8acf9679bf9269f7bf"
print(base64.b64encode(bytes.fromhex(h)).decode())
```
