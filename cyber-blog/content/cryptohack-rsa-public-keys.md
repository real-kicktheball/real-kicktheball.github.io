## 개념

RSA는 **우체통**과 비슷하다.

- **공개키**는 우체통 입구다. 누구나 편지(메시지)를 넣을 수 있다.
- **비밀키**는 우체통 열쇠다. 주인만 꺼낼 수 있다.

공개키는 숫자 두 개 $(N, e)$이고, 암호화는 이렇게 한다.

$$
c = m^e \bmod N
$$

### 직접 해보기 (작은 RSA)

$p = 3$, $q = 11$로 $N = 33$을 만들고, $e = 3$, 메시지 $m = 4$라고 하자.

$$
c = 4^3 \bmod 33 = 64 \bmod 33 = 31
$$

암호문은 31이다. 31만 보고 원래 4였다는 걸 알아내기는 (숫자가 크면) 매우 어렵다.

| 용어 | 뜻 |
|---|---|
| $N$ | 두 소수를 곱한 큰 수(모듈러스) |
| $e$ | 공개 지수. 보통 65537을 쓴다 |
| $m$ | 평문(숨길 메시지를 숫자로 바꾼 것) |
| $c$ | 암호문 |

### 정리

RSA 키 생성은 다음 순서로 한다.

1. 큰 소수 $p$, $q$를 고르고 $N = pq$를 만든다.
2. 공개 지수 $e$를 정한다. 보통 $65537 = 2^{16}+1$을 쓴다.
3. **공개키**는 $(N, e)$이고, 누구나 이걸로 암호화할 수 있다.

$$
c = m^e \bmod N
$$

$e = 65537$은 비트가 1인 자리가 두 개뿐이라 암호화가 빠르다. 동시에 너무 작은 $e$(예: 3)에서 생기는 공격도 피할 수 있다.

## 문제

$p = 17$, $q = 23$, $e = 65537$일 때 $m = 12$를 암호화한다.

## 풀이

$N = 17 \cdot 23 = 391$이고, $c = 12^{65537} \bmod 391 =$ **301**이다.

## 풀이 코드
```python
p,q,e,m = 17,23,65537,12
N=p*q
c=pow(m,e,N)
assert 0 <= c < N
print(c)
```

## 정답
`301`
