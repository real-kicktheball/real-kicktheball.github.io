## 개념

컴퓨터는 사실 **숫자밖에 모른다**. 그래서 글자를 저장하려면 "어떤 글자는 몇 번" 하고 약속을 정해야 한다. 이 약속표가 **ASCII(아스키)**다.

반 친구들에게 출석번호를 붙이는 것과 같다.

| 글자 | 번호 |
|---|---:|
| A | 65 |
| B | 66 |
| a | 97 |
| c | 99 |
| { | 123 |
| } | 125 |

이 문제는 출석번호 목록 `99, 114, 121, 112, 116, 111, 123 ...`을 주고 "이 번호의 친구들 이름을 불러봐"라고 하는 것이다.

### 직접 해보기

- 99 → `c`
- 114 → `r`
- 121 → `y`
- 112 → `p`
- 116 → `t`
- 111 → `o`
- 123 → `{`

이어 붙이면 `crypto{`가 된다. 파이썬에서는 `chr(99)`라고 쓰면 `c`가 나온다. 반대로 `ord('c')`는 99다.

### 정리

**ASCII**는 문자 하나를 0~127 사이의 정수 하나로 나타내는 7비트 인코딩이다. 예를 들어 `'c'`는 99, `'{'`는 123이다.

파이썬에서는 두 방향 변환을 쓴다.

- `ord('c') = 99`: 문자 → 정수
- `chr(99) = 'c'`: 정수 → 문자

## 문제

정수 배열 `[99, 114, 121, 112, 116, 111, 123, ...]`이 주어진다. 이를 문자로 바꾸라는 문제다.

## 풀이

앞부분만 봐도 99, 114, 121, 112, 116, 111, 123은 `c r y p t o {`이다. 배열 전체에 `chr`을 적용해 이어 붙이면 플래그가 된다.

## 풀이 코드
```python
values = [99,114,121,112,116,111,123,65,83,67,73,73,95,112,114,49,110,116,52,98,108,51,125]
print(''.join(map(chr, values)))
```

## 플래그
```text
crypto{ASCII_pr1nt4bl3}
```
