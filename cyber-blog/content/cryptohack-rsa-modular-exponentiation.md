## 개념

RSA 암호는 **"어떤 수를 여러 번 곱하고 나머지 구하기"** 하나로 만들어진다. 그런데 곱하는 횟수가 수백 자리 숫자만큼 많다. 하나씩 곱하면 우주가 끝나도 못 끝낸다.

그래서 **제곱을 이용해 점프**한다.

### 직접 해보기 ($3^{13} \bmod 7$)

13을 2의 거듭제곱의 합으로 쪼갠다: $13 = 8 + 4 + 1$

제곱을 반복해서 필요한 조각을 만든다. 매번 7로 나눈 나머지만 남긴다.

| 조각 | 계산 | 7로 나눈 나머지 |
|---|---|---:|
| $3^1$ | 3 | 3 |
| $3^2$ | $3 \times 3 = 9$ | 2 |
| $3^4$ | $2 \times 2 = 4$ | 4 |
| $3^8$ | $4 \times 4 = 16$ | 2 |

$3^{13} = 3^8 \times 3^4 \times 3^1$이므로 $2 \times 4 \times 3 = 24 \equiv 3$이다.

13번 곱하는 대신 곱셈 몇 번으로 끝났다. 지수가 아무리 커도 "지수의 자릿수"만큼만 계산하면 된다. 이걸 **제곱-곱셈(square-and-multiply)**이라 한다.

### 정리

RSA의 암호화와 복호화는 모두 **모듈러 거듭제곱**이다.

$$
c = m^e \bmod N, \qquad m = c^d \bmod N
$$

$e$나 $d$는 수백~수천 비트라서 $m^e$를 그대로 계산하면 숫자가 감당할 수 없이 커진다. 그래서 **제곱-곱셈(square-and-multiply)** 방식을 쓴다.

- 지수를 이진수로 보고, 각 비트마다 결과를 제곱한다.
- 비트가 1이면 밑을 한 번 더 곱한다.
- 매 단계마다 $\bmod N$을 해서 숫자 크기를 $N$ 이하로 유지한다.

파이썬의 `pow(base, exp, mod)`가 이 방식으로 동작한다.

## 문제

$101^{17} \bmod 22663$을 구한다.

## 풀이

$17 = 10001_2$이다. 그래서 $101$을 4번 제곱해 $101^{16}$을 만들고, 여기에 $101$을 한 번 곱하면 된다. `pow(101, 17, 22663)` = **19906**이다.

## 풀이 코드
```python
result = pow(101,17,22663)
assert result == 101**17 % 22663
print(result)
```

## 정답
`19906`
