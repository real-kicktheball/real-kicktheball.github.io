# black_nut

[블로그](https://real-kicktheball.github.io/)

나이츠 프론티어를 진행하면서 한 활동들을 기록하는 블로그다. 나이츠 프론티어와 관련 없는 글은 올리지 않는다.

## 글 수정하기

글은 `cyber-blog/content/`에 있다. 파일 이름이 글 주소가 되므로 기존 글을 수정할 때는 이름을 그대로 둔다.

파일 앞부분의 `---` 안에는 JSON으로 글 정보를 적는다. `section`은 카테고리 아래 폴더 경로이고, 폴더 없이 카테고리 바로 아래에 두려면 `[]`로 비워 둔다.

```markdown
---
{"title":"글 제목","date":"2026-10-27","category":"writing","section":[],"tags":["나이츠 프론티어"],"summary":"무엇을 정리한 글인지 한 줄로"}
---

## 활동 내용

여기부터 본문.
```

카테고리 값은 다음 여섯 개를 쓴다.

| 값 | 메뉴 |
| --- | --- |
| `development` | 개발 |
| `ctf` | CTF/Wargame |
| `bug-bounty` | Bug Bounty |
| `writing` | 블로그/기술문서 |
| `research` | 논문/컨퍼런스 |
| `challenges` | 공모전/자격증 |

코드 블록에 `python`, `cpp`, `sql`처럼 언어 이름을 붙이면 색상이 들어간다.

````markdown
```python
print("hello")
```
````

## 실행과 배포

Node.js 22 이상이 필요하다.

```sh
cd cyber-blog
npm ci
npm run build
npm run check
```

빌드 결과는 `docs/`에 생긴다. `main`에 변경 사항을 올리면 GitHub Actions가 빌드와 링크 검사를 거쳐 Pages에 배포한다. 화면을 고칠 때는 `cyber-blog` 안의 파일을 수정하면 된다. Windows에서는 `npm run check`가 경로 구분자(`\`) 때문에 실패할 수 있다. 배포에 쓰는 Linux 환경에서는 문제가 없다.

| 파일 | 용도 |
| --- | --- |
| `site.json` | 소개 문구와 카테고리 |
| `build.mjs` | HTML 생성, 폴더 트리, 코드 색상, 고정 글 목록(`pinnedSlugs`) |
| `assets/style.css` | 화면 스타일 |
| `assets/app.js` | 검색, 테마 버튼, 카테고리 파일 목록, 카테고리 펼침 애니메이션 |
| `assets/terminal.js` | 터미널 명령과 창 관리 |
| `assets/matrix.js` | 모니터 화면의 문자 효과 |
| `assets/intro.js` | 홈 진입 시 실제 모니터 화면의 확대·축소와 문구 디코딩 |
| `assets/navigation.js` | 페이지 이동, 상단 메뉴의 숫자 커튼콜 전환 |
| `assets/window-motion.js` | 파일탐색기·터미널 축소와 복원 연출 |

`build.mjs`의 `pinnedSlugs`에 적은 글이 없으면 빌드가 실패한다. 고정 글로 쓰던 글을 지울 때는 이 목록도 함께 고친다.

## 화면 사용법

탭에서 사이트에 처음 들어올 때 홈 화면이라면 실제 모니터 화면이 전체 화면으로 펼쳐진 상태에서 시작한다. 모니터 안의 문구가 Base64에서 한 글자씩 천천히 디코딩되는 동안 숫자와 영문자는 계속 떨어진다. 이후 같은 화면이 모니터 안으로 축소된다. 상단 `black_nut` 로고는 제자리에 고정된다. `기록 열기`를 누르면 진행 중인 인트로를 끝내고 기록 목록으로 부드럽게 내려간다. 메인에서는 카테고리를 펼쳐 폴더와 글을 찾을 수 있다. 카테고리나 폴더를 펼치면 목록이 위에서 아래로 자연스럽게 내려온다. 파일이 많은 폴더는 처음 40개를 보여 주며 아래의 `다음 파일 보기`로 이어서 불러온다. 메인·최근 기록 카드와 카테고리 파일을 열면 선택한 항목이 글 화면으로 확장되고 제목은 글 제목 자리로 이동하며 본문이 위에서 아래로 나타난다. 파일탐색기에서 MD 파일을 열면 창이 하단 메뉴로 축소된 뒤 글이 표시된다. 창을 내리거나 복원할 때도 같은 축소·복원 연출을 사용한다. 글 페이지에도 현재 글의 카테고리 경로가 펼쳐진다. 하단 파일탐색기 버튼으로는 폴더별 목록과 검색 창을 열 수 있다. 화면에 들어온 텍스트는 처음 한 번 글자별로 나타나며, 터미널과 파일탐색기 창은 글 사이를 이동해도 유지된다.

상단 메뉴로 이동할 때는 모니터에 숫자가 떨어지는 것 같은 커튼콜 전환이 나온다. `black_nut` 로고는 위에서 아래로, `소개`는 오른쪽에서 왼쪽으로, `홈`은 왼쪽에서 오른쪽으로 숫자가 흐르며 화면을 덮고 걷힌다. 밝은 테마에서는 커튼콜 색도 밝게 바뀐다. 시스템에서 동작 줄이기를 켜 두면 효과 없이 바로 이동한다.

새 터미널을 열면 환영 문구와 프롬프트가 한 글자씩 출력된다. 터미널에서도 `ls`, `cd`, `cat`, `open`으로 글을 찾을 수 있다. 예를 들어 `cd writing` 다음에 `ls`를 입력하면 된다. 전체 명령은 `help`에 있다. 오른쪽 `⋮`로 창을 추가하고, 같은 화면에서 글 페이지를 옮겨도 경로와 명령 기록이 유지된다. 브라우저 창을 닫거나 페이지를 새로 열면 창·효과·테마 상태는 초기화된다.

화이트·블랙 테마는 버튼을 누르면 서서히 전환된다. 문자 효과는 처음에 켜져 있다. 하단 `01 효과` 버튼으로 끌 수 있다. 본문의 텍스트 선택과 브라우저 복사·붙여넣기는 막아 두었다. 공개된 파일 자체를 보호하는 기능은 아니다.
